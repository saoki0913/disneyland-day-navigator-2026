- Cloudflare と GitHub のネイティブ Git 連携は使いません（Cloudflare Git installation が 8000011 で失敗するため）。代わりに公式サポートの `wrangler pages deploy public --project-name dl-navi-1031 --branch main` を使います。

- Secret 未設定の場合、自動デプロイのジョブが明確なエラーで失敗し、現在公開中のアプリはそのまま動きます。
- 本番デプロイは **既存の `dl-navi-1031` Pages** だけです。`mogup-api`、`career-compass-web-production`、`career-compass-web-staging`、`usa-trip-disney-day-1031`、他の Pages、DNS、ルート、カスタムドメイン、他サービスの環境変数・シークレット・課金設定には触れません。

## 画面と使い方

| タブ | できること |
|---|---|
| **いま** | 次に行くべき場所（大きなカード）：待ち時間・徒歩目安・終了見込み・おすすめ理由。「乗り終わった」「ルートを見る」「別の候補」。判断基準別の候補（待ち時間優先／距離優先／人気度優先）、このあとの予定、現在地、データの鮮度 |
| **プラン** | A ゆったり／B バランス（初期）／C アトラクション重視 の切替。今から閉園までの予定を自動計算（食事・ショー込み）。体験済みチェック、食事の時間・店の変更、「最新の待ち時間で組み直す」 |
| **マップ** | 待ち時間色分けのピン、食事・ショー、現在地（GPS許可時）、次の目的地への直線（点線）と Google マップの徒歩ルート |
| **探す** | 写真付きアトラクション一覧（待ち時間・スリル・人気・日本との違い）、フィルタ・並べ替え、グルメ（メニュー・料金目安・モバイルオーダー）、ハロウィン限定（ポップコーンバケット・限定フード） |
| **ショー** | 次のショーまでのカウントダウン、花火＋ファンタズミックの動線、回の選択、プランへの追加/除外、時刻の手動修正 |

当日の流れ：開いたら「いま」の大きなカードの通りに動く → 乗ったら画面下の大きな「✓ ○○ 乗った！」→ 次のおすすめが自動で更新。

- **完了の記録**：押すと即完了（トーストで取り消し可）。完了したものはプランタブの「✅ 完了したこと」に時刻つきで残り、
  タップすると確認してから未完了に戻せる（戻した後もトーストで再び完了にできる）。
- **再開・急減アラート**：休止していた施設の再開や、人気施設の待ち時間の急減（15分以上かつ3割以上）を画面上部に表示。
  「行く！」で次の行き先に固定。Androidは振動あり（iPhoneのSafariは振動非対応）。
- **待ち時間の推移**：アプリが取得した今日の実測値を端末に記録し、一覧に小さな折れ線＋↘↗、詳細に推移グラフ（推定は点線）を表示。
- **片手操作**：「乗った」「別の候補」は画面下に固定の大ボタン。
- **ホーム画面に追加**：iPhoneの手順をアイコンで案内（全画面・電波が弱くても起動）。
- **写真**：Wikimedia Commons から実際のディズニーランドの施設・店舗・ショーの写真をサーバーが検索（他パーク・ロゴ・小画像は除外、
  作者・ライセンス表示）。見つからなければ Wikipedia の記事画像 → イラストタイルの順に代替。

## データの扱い（偽装しないためのルール）

- **待ち時間**：ThemeParks.wiki（主）→ 失敗時 Queue-Times.com（予備）。Pages Function がエッジで60秒キャッシュし、
  画面表示中は3分ごとに自動更新。表示ラベル：`LIVE`（外部提供値）／`手入力`（公式アプリを見て入力）／`推定`（過去傾向の計画用の値）。
  15分以上古いデータは使わず推定に切り替え、バナーで明示。
- **ショー時刻**：APIから取得できればそれを使用（「APIの公式時刻」）。取得できない場合は事前情報として「要確認」と表示。手動修正可。
- **座標**：ThemeParks.wiki の施設座標を使用。取得できない場合は概略位置であることを表示。
- **徒歩時間**：直線距離×1.4 ÷ 分速70m の目安。実際の道順は Google マップへ。
- **位置情報**：「現在地を使う」を押した時のみ取得し、端末内の計算にのみ使用（サーバー送信なし）。
- **写真**：Wikimedia Commons（実物の写真・作者とライセンス表示）→ Wikipedia → イラストタイル。
- **進捗**：ブラウザの localStorage に保存（リロードしても保持）。

## 最適化アルゴリズム（概要）

`public/js/engine.js`（DOM非依存・テスト済み）

1. 次の固定予定（食事・ショー）までに「移動＋待ち＋乗車＋次の予定地点への移動」が収まるアトラクションだけを候補にする。
2. スコア = 人気 + ユーザー優先度 + 必須ボーナス（残り時間が少ないほど増加）− 待ち時間×重み − 徒歩×重み
   ＋「いつもより空いている」ボーナス ＋「この後混む」ボーナス。重みはプランごとに異なる。
3. 必須（スター・ウォーズ2施設）は休止中でも除外しない。入りきらない場合は、任意の予定（おやつ休憩・カヴァルケード）を
   後ろにずらす/別の回にする/見送る、ショーの場所取りを短縮する、閉園までに列に並ぶ、の順で救済し、理由を表示。
4. プランタブはこの推薦を閉園まで前向きにシミュレーションしたもの（30分以降は推定待ち時間を当日の混雑比で補正）。
